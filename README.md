# Telegram Music Player Bot - ПРЕДВАРИТЕЛЬНАЯ идея Калхиева Соса

## 1. Идея проекта

Telegram-бот для хранения и управления личной музыкальной библиотекой.

- Аудиофайлы хранятся в Telegram.
- Сервер хранит только метаданные и логику.
- Управление через команды и inline-кнопки.
- Получение песен, альбомов и плейлистов в личных сообщениях с ботом.

## 2. Основные функции

### Музыкальная библиотека
- Добавление аудио через пересылку или загрузку.
- Хранение названия, исполнителя, альбома и длительности.
- Поиск по названию, исполнителю и альбому.
- История добавленных треков.
- Удаление треков.

### Альбомы
- Создание, редактирование и удаление.
- Добавление и удаление треков.
- Исполнитель, год, обложка и описание.
- Изменение порядка треков.
- Перемешивание треков.
- Отправка альбома или отдельных песен.

### Плейлисты
- Создание и удаление.
- Добавление треков из разных альбомов.
- Изменение порядка.
- Перемешивание.
- Копирование плейлистов.
- Отправка плейлиста или отдельных треков.

### Избранное
- Добавление и удаление треков.
- Просмотр избранного.
- Перемешивание.
- Отправка избранных треков.

### Тексты песен
- Добавление текста вручную.
- Редактирование и удаление.
- Просмотр текста из карточки трека.

## 3. Команды

/start       Запуск бота
/menu        Главное меню
/help        Список команд
/search      Поиск
/library     Библиотека
/albums      Альбомы
/playlists   Плейлисты
/favorites   Избранное
/recent      Недавно добавленные
/add         Добавить музыку
/settings    Настройки
/cancel      Отмена действия

Дополнительные операции с альбомами и плейлистами выполняются через inline-кнопки.

## 4. Добавление музыки

- Пересылка аудио из другого чата.
- Загрузка аудиофайла.
- Получение метаданных из Telegram.
- Редактирование названия и исполнителя.
- Выбор альбома или плейлиста после загрузки.
- Массовое добавление треков.

## 5. Отправка музыки

- Отправка отдельного трека.
- Отправка альбома.
- Отправка плейлиста.
- Отправка случайного трека.
- Перемешивание порядка отправки.
- Использование сохранённого Telegram file_id.

Бот не управляет системным проигрывателем телефона. Он отправляет аудиофайлы в Telegram.

## 6. Интерфейс

- Главное меню с inline-кнопками.
- Постраничная навигация.
- Кнопки «Назад» и «Главное меню».
- Контекстные действия для альбомов и плейлистов.
- Режим добавления нескольких треков.
- Подтверждение удаления.
- FSM для многошаговых операций.

## 7. Хранение данных

Использовать PostgreSQL.

Таблицы:
- users
- tracks
- albums
- album_tracks
- playlists
- playlist_tracks
- favorites
- user_sessions

Данные трека:
- Название.
- Исполнитель.
- Альбом.
- Длительность.
- Telegram file_id.
- Telegram file_unique_id.
- ID исходного сообщения.
- Текст песни.
- Дата добавления.

## 8. Технологии

- Python 3.12+
- aiogram 3.x
- PostgreSQL
- SQLAlchemy
- Alembic
- Docker
- Redis (опционально)

## 9. Ограничения

- Не хранить аудиофайлы постоянно на сервере.
- Ограничить доступ по Telegram User ID.
- Изолировать данные пользователей.
- Учитывать ограничения Telegram Bot API.
- Создавать резервные копии базы данных.
- Не использовать Telegram как гарантированное бессрочное резервное хранилище.

## 10. Приоритет разработки

1. Добавление и хранение треков.
2. Альбомы и плейлисты.
3. Отправка музыки.
4. Избранное.
5. Поиск.
6. Удобный интерфейс.
7. Тексты песен.
8. Дополнительные функции: теги, дубликаты, умные плейлисты.
